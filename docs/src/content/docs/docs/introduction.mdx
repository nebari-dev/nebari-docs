## What is Nebari?

**Nebari is an open-source ecosystem for AI platforms.** Teams choose ready-made AI tools from a shared catalog, such as chat assistants, document analysis, image generation, and code review, and install them on a platform they control.

Teams pick only the components they need, keeping their stack lightweight, cost-effective, and simple to maintain.

## Why choose Nebari?

Building a modern AI platform typically comes down to two approaches:

- **Build it yourself**: assemble Kubernetes, auth, storage, observability, and more, then maintain it over time. It takes months, and every team re-solves the same integration problems.
- **Use a ready-made platform**: faster to start, but you are tied to its choices and customization is not easy.

Nebari combines both: ready-made building blocks to design your platform, with the freedom to create and customize your own.

## Key features

- **Composable**: install only the tools your team needs, and add more over time.
- **Open ecosystem**: no single vendor controls what you can install. Choose tools from OpenTeams, your own team, or the open-source community.
- **Built-in foundations**: every tool is automatically secured, connected, and made accessible through the [landing page](/docs/references/glossary/#landing-page). No wiring required.
- **Runs on your infrastructure**: your own cloud account, such as AWS or Hetzner, or your laptop for testing.
- **Open source**: every part of Nebari is open for inspection, modification, and contribution.

## How Nebari works

Nebari has two parts: **Software Packs**, which add the Services your team uses, and **Deploy Targets**, the environments they run on.

<EcosystemDiagram />

### Software Packs

A **Software Pack** is an installable artifact published to a GitHub repository. Each pack is self-contained, so teams can browse what's available and install only the ones they need. Packs come from two channels:

- **Official packs** by OpenTeams: enterprise-grade and curated, published under the [`nebari-dev`](https://github.com/nebari-dev) GitHub organization.
- **Community packs** by open-source contributors: published on GitHub by individual maintainers or by businesses building on Nebari.

### Capabilities

A **Capability** is something a team can do with the platform once a Software Pack is installed, like analyzing documents or running a chat assistant. The same Capability can be delivered by different packs. Current examples include:

- Document analysis
- Code review
- Image generation
- Data extraction
- Chat assistants
- Report builders

### Deploy Targets

A **Deploy Target** is a kind of environment Nebari can be deployed to.

Today, Nebari runs on Kubernetes through **Nebari Kubernetes Platform (NKP)**. NKP sets up a Kubernetes cluster with the foundational software that Software Packs build on. You set it up with [NIC](/docs/references/glossary/#nic), Nebari's command-line tool.

Additional targets are planned:

- Bare metal
- Edge devices
- HPC clusters
