The [Nebari Kubernetes Platform (NKP)](/docs/references/glossary/#nkp) is an AI platform your team runs on infrastructure you control. Sign-in, secure web addresses, and updates through Git are set up for you, so you don't have to build them yourself.

You deploy it with **`nic`**, a command-line tool that reads one configuration file and provisions the whole thing on the cloud provider you choose. Once the platform is running, you add [Software Packs](/docs/software-packs/) for the capabilities your team actually wants, such as notebooks, dashboards, or model serving.

## Who this is for

You'll be the person who deploys and operates the platform for your team. You don't need Kubernetes experience, just comfort running commands in a terminal.

## Where to go next

The quickstart gets you a working cluster and then removes it, so you can see the whole cycle before committing to anything.

When you're ready to run a cluster your team will actually use, work through your [provider's how-to guide](/docs/how-tos/providers/) instead. Those cover the parts the quickstart skips: sizing your nodes, cost planning, DNS, creating user accounts, and backups.

To understand what `nic` builds and why, read [NKP architecture](/docs/explanations/nkp-architecture/).
